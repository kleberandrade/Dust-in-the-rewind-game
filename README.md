## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/Congratulations.unity](https://github.com/kleberandrade/Dust-in-the-rewind-game/blob/master/Assets/Scenes/Congratulations.unity), [Assets/Scenes/Credits.unity](https://github.com/kleberandrade/Dust-in-the-rewind-game/blob/master/Assets/Scenes/Credits.unity), [Assets/Scenes/Gameover.unity](https://github.com/kleberandrade/Dust-in-the-rewind-game/blob/master/Assets/Scenes/Gameover.unity), [Assets/Scenes/Gameplay.unity](https://github.com/kleberandrade/Dust-in-the-rewind-game/blob/master/Assets/Scenes/Gameplay.unity), [Assets/Scenes/Intro.unity](https://github.com/kleberandrade/Dust-in-the-rewind-game/blob/master/Assets/Scenes/Intro.unity).
